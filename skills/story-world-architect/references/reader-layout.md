# 读者设定集默认书籍排版

`assets/reader-template.docx` 保存本技能的默认书籍级样式；用户提供新的参考文档时优先继承用户参考。

## 页面与文字规范

| 部位 | 默认显示格式 |
|---|---|
| 页面几何 | 标准 A4（21.00 × 29.70 cm）；上 2.40 cm、下 2.20 cm、左右 2.60 cm |
| 页眉页脚 | 距边缘 1.20 cm；首页不显示页眉页码；其余页展示项目名与页码 |
| 封面 | 微软雅黑 26 磅加粗居中（墨黛蓝 `#1B263B`），副标题 13 磅（青灰 `#5C677D`） |
| 正文（`Reading Body`） | 宋体 11.5 磅（暖墨黑 `#222222`），1.48 倍行距，段后 4.5 磅，首行缩进 2 字符（23 磅） |
| 一级标题 | 微软雅黑 18 磅加粗，墨黛蓝 `#1B263B`，章首另起新页，与下段同页 |
| 二级标题 | 微软雅黑 15.5 磅加粗，黛蓝 `#2B4C7E`，段前 16 / 段后 8 磅，与下段同页 |
| 三级标题 | 微软雅黑 13.5 磅加粗，玄青灰 `#3D405B`，段前 12 / 段后 6 磅，与下段同页 |
| 四级标题 | 微软雅黑 12.5 磅加粗，赭石暗金 `#9C4A1A`，段前 10 / 段后 5 磅，左缩进 240 twip，独立 `Heading 4` 语义 |
| 目录标题 | 微软雅黑 18 磅加粗（墨黛蓝 `#1B263B`；中文默认“目录”，英文可通过 `--toc-title Contents` 切换） |
| 目录一/二/三/四级 | 微软雅黑 12 / 11 / 10.5 / 10 磅；一级加粗，四级左缩进 780 twip；右侧点引导线页码 |

`Heading 1–4` 保留真实 Word 大纲级别与语义，不用局部加粗冒充标题层级；`Contents 4` 同样采用独立角色样式。所有角色样式均显式写入 `ascii`、`hAnsi`、`eastAsia`、`cs` 四个字体槽位，消除跨环境主题字体漂移。

## 模板槽位与构建约束

模板正文包含 `{{WORLD_TITLE}}`、`{{WORLD_SUBTITLE}}`、`{{TOC}}`、`{{BODY}}` 四个编辑槽；页眉含 `{{WORLD_TITLE}}`，页脚为 `PAGE` 字段。构建器自动清空槽位并填入正文与真实书签跳转，成稿绝不残留占位符。

初次渲染导出 PDF 后，按 PDF 书签真实页码回填目录并重新导出核对，直至目录页码稳定。章末稀疏页由人工结合视觉渲染判断，不通过机械删减正文或压缩字号来消除提醒。

## 可调整边界

页面开本、字体字号、色彩搭配、封面与目录语言均可随用户需求或新参考模板定制；提取新模板可运行 `scripts/extract_reader_template.py`。
