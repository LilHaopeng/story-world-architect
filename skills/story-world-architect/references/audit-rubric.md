# 世界观可行性与审计规则

审计、修订、交接和锁定前读取。结论必须引用具体规则、制度、势力、冲突、种子或源材料。

## 1. 结论与严重度

- `可进入大纲`：无阻断项；接口已标明硬规则、开放项和禁用假设。
- `修订后可行`：核心世界成立，但存在会污染大纲的断链或冲突。
- `当前不可行`：核心规则彼此矛盾，或承诺的故事无法从世界条件中产生。

| 级别 | 含义 | 处理 |
|---|---|---|
| S0 阻断 | 正典冲突、硬规则不可共存、时间/资源不可能、接口引用不存在 | 停止交接或锁定 |
| S1 重大 | 万能能力、制度无执行者、风险流断裂、时代危机无因、核心冲突可轻易消失 | 本阶段修复 |
| S2 中等 | 模块孤立、势力扁平、日常证据不足、种子重复、二阶后果缺失 | 给出修订计划 |
| S3 增强 | 命名、地域质感、礼仪细节、可选旁支 | 不阻塞 |

任何 S0 或未解决 S1 都不能被总分抵消。

基调、现实参照、时间与金额口径同时对照 [design-anchors.md](design-anchors.md)。审计不等于把所有制度修成理想社会，也不等于一律添加阴暗面。用户选择的现实参照与表述范围不是普世政体规则；不得用政治词扫描代替可行性审查。

## 2. 九个审查视角

### 范围与承诺

- 世界复杂度是否匹配故事体量与类型承诺。
- 是否明确不展开范围；有没有为“完整”而构建不影响故事的百科条目。
- 世界常态、时代异常和“为什么是现在”是否清楚。

### 规则一致性

- `hard / soft / belief / open / retired` 是否分明。
- 规则的条件、边界、例外、可观察性与反制是否稳定。
- 例外是否只在主角需要时出现；不同文件是否给出冲突版本。

### 因果与涌现

- 事实是否经过分配、激励和制度形成压力，而非直接跳成剧情结论。
- 去掉某个预设角色决定后，冲突是否仍能产生多种合理行动。
- 结果是否产生二阶影响和新状态，而非世界自动复位。

### 资源、能力与风险流

- 稀缺资源由谁控制、生产、运输、维护和替代。
- 技术/力量如何影响非战斗领域，扩散和事故如何处理。
- 钱、风险、责任、信息和尾部损失从谁流向谁；是否存在无承担者的收益。

### 制度与治理能力

- 权力/权利由谁授予，谁执行，覆盖范围与成本是什么。
- 正常、失败、欺诈、执法、申诉和绕过是否都有可行机制。
- 纸面规则与实际执行能力是否区分；制度为何获得服从或社会授权。

### 社会、文化与日常

- 阶层流动是否有真实门槛和多条路径。
- 文化是否通过名誉、礼仪、教育、家庭、消费、禁忌或惩罚改变行为。
- 普通人能否在住房、职业、婚姻、出行、医疗、税费和信息中感受到核心规则。

### 历史、信息与认知

- 历史事件是否留下仍在付息的债务，而非年表装饰。
- 作者真相、公众认知、势力认知和角色知识是否分离。
- 信息能否被记录、验证、传播、垄断、伪造和追溯；秘密的保护成本是否合理。

### 势力与结构冲突

- 势力是否有独立目标、资源、约束、策略、依赖、可接受损失和决策机制。
- 高度统一是否有维持机制；内部差异是否真实影响决策。
- 冲突是否由结构持续供能，为什么不能靠一次谈判或消灭坏人解决。

### 剧情生产与交接

- 每个种子是否有来源冲突、触发器、个人入口、两难、代价和状态变化潜力。
- 种子是否允许不同选择，而非伪装成已写好的大纲。
- 大纲接口是否固定版本、引用有效 ID、列出禁用假设和开放问题。

## 3. 诊断指标

指标用于定位，不是普适录取线。短篇、寓言、关系剧可用较少模块，但必须覆盖本作的主要压力链。

### 因果闭环率

`已完成“约束→分配→激励→制度/策略→冲突或日常后果”的核心设定数 ÷ 核心设定总数`

仅有名词、历史描述或“因此社会动荡”不算闭环。

### 剧情生产率

`能产生至少两种有代价人物选择的活跃结构冲突数 ÷ 活跃结构冲突总数`

不是要求无限产梗；目标是避免只有唯一作者答案的假冲突。

### 规则可预测性

`条件、边界、例外和证据均已说明的 hard 规则数 ÷ hard 规则总数`

可预测不等于角色全知，也不要求精确数值化。

### 制度可执行率

`已说明授权、执行、覆盖、失败和绕过的核心制度数 ÷ 核心制度总数`

制度型题材的警戒优先级高于装饰性题材。

### 下游可追踪率

`大纲接口中能回指有效 RULE/CON/SEED 的引用数 ÷ 接口引用总数`

目标为 100%；无效引用属于 S0。

### 冲突多样性

比较活跃种子的主要压力来源：资源、身份、关系、信息、制度、价值、时间、生存。若所有种子只是“更强敌人/更大事故”，判为重复风险。

## 4. 100 分量表

| 维度 | 分值 | 核心证据 |
|---|---:|---|
| 核心约束与规则一致性 | 15 | 正典清楚、边界稳定、例外受控 |
| 因果链与二阶后果 | 15 | 从约束推到激励、制度、压力和新状态 |
| 资源/能力/风险流 | 10 | 获益者、损失者、承担者与扩散机制 |
| 制度与治理可信度 | 15 | 授权、执行、失败、执法、规避和社会授权 |
| 社会文化与日常可见性 | 10 | 设定改变普通人的可观察生活 |
| 历史、信息与认知 | 10 | 历史债务、知识分层、信息基础设施 |
| 势力与结构冲突 | 10 | 独立策略、依赖网络、持续供能 |
| 剧情种子质量 | 10 | 入口、两难、代价、升级与多种选择 |
| 状态与大纲接口 | 5 | 当前/拟议分离、版本和引用稳定 |
| 总分 | 100 | 阻断项优先于总分 |

建议解释：`<75` 需重构；`75–84` 可修；`85–91` 无阻断项时可交接；`92+` 结构强，但仍需实际大纲和正文验证。每次评分都附证据和最小修复。

## 5. 专项压力测试

### 能力/技术

1. 谁能获得，门槛是什么。
2. 使用和维护受到什么边界控制。
3. 谁能观察、复制、封锁或反制。
4. 它如何改变生产、军事、医疗、治安和家庭生活。
5. 为何社会没有被它推向另一种明显均衡。

### 经济/金融

1. 权利和债权如何登记、转让、清算与执行。
2. 收益从哪里来，风险和尾部损失落在谁身上。
3. 参与者为何自愿或被迫参与。
4. 正常、违约、欺诈、挤兑、救助和退出如何发生。
5. 信息不对称、资本约束和监管套利如何反馈到阶层与政治。

### 法律/政治

1. 正式授权与实际权力是否一致。
2. 管辖、证据、程序、执行和申诉是否成立。
3. 中央命令到地方执行的损耗在哪里。
4. 制度有哪些真实受益者；拆除它会伤害谁。
5. 反对者为何不能更早、更便宜地解决问题。

### 战争/灾难

1. 动员、补给、通信、训练和伤亡替代如何维持。
2. 胜利条件和可接受损失是否因势力而异。
3. 平民、财政、合法性和基础设施承受什么二阶后果。
4. 危机为何升级或无法迅速降温。
5. 战后新均衡是否被预先考虑。

### 制度起源、基调与技术冲击

1. 发起者、旧问题、参与动机、反对与妥协是否具体；为何能长期维持，其他地区为何采用或拒绝。
2. 正常收益、失败损失、寻租或规避的条件是否成立；若无可信规避，是否说明约束，避免为凑数造犯罪。
3. 救济的资格、额度、申请、等待、资金或资源来源及实际覆盖是否与已确认基调一致；有效帮助是否被无故取消，冷峻约束是否被万能兜底抹掉。
4. 技术替代如何改变岗位数量、工资、资产与旧义务；监管、维护、基础设施及扩散需要多久；损失最终流向何人。
5. 信用、估值、登记、货币与真实产出是否混为一谈；模型误差与集中失业是否被“预测准确”一句跳过。

残酷设定被无依据的免费解法消除，按其对核心因果的影响定级；温暖世界没有犯罪不自动构成 S1。每条发现引用具体材料，指出与哪项已确认边界冲突。

### 时间、金额与地域一致性

1. T0、制度先后与人物年龄可否回算；相对纪年也需一致，生日前后不误作精确值。
2. 技术出现、采用、扩散与大规模冲击有否混写；未来推演有否误写成现实已发生的事实。
3. 无现金等媒介变革发生后，黑市、灾备、礼金和赎回使用什么载体；无现金不等于没有会计“现金流”，也不等于物物交换会自动消失。
4. 法定货币、相对购买力、价格指数与汇率的单位/地区/日期是否清楚；换算和分位方向是否正确，例子能否复算。
5. 外域与主舞台共享什么、改变什么、如何互认或拒绝；差异有无理由，人物迁移后能否凭空摆脱全世界 hard 规则。
6. 高可用声明有无对象、时间窗口和范围；一次末端断连是否被夸成全网失效，罕见事故是否被写成每年必发。

时间/数值出现不可能关系按 S0 处理；未给绝对币名或公历年本身不是缺陷，若相对尺度足以支撑阅读与因果，应保留开放。

### 运行机制、反馈与价值差异

需要检查设定与行动脱节时，参照 [design-anchors.md](design-anchors.md) 的三项方法，沿实际材料检查：

1. **资源—权力反馈**：收益如何维持或扩大控制？维护成本、外部依赖、替代与改变通道在哪里？不要把“某组织垄断”当作解释终点，也不因不存在压迫性垄断判为不合格。
2. **条件与反馈**：关键后果是否注明条件、范围和传播时延？参与者应对、替代方案与后续反馈是否可能改变结果？不以“有魔法/技术”直接证明某产业必然消失。
3. **价值—行为落差**：公开倡导、实际奖惩、私人信念和行为是否被混同？文化内的差异与不平等的解释权是否有具体依据？不因人物反对主流规范就直接判为世界观冲突。

对影响本作的核心机制，可补无主角运行与移除设定检查。报告具体哪条因果链断开、哪些选择没有受影响、哪些结论仍是推测，再按既有严重度处理。不用完成检查项的数量打分，不要求每条规则产生斗争，不把装饰细节或温暖合作世界误判成不可行；也不把结构性压力直接当成预定剧情。

## 7. 读者版审查

仅在产物面向爱好者、休闲读者，或用户要求检查阅读体验时启用，结合 [reader-edition.md](reader-edition.md)。它补充上述世界语义审查，不替代规则、因果、制度和风险审计，也不把小说情节推进速度当成设定集标准。

分别报告两类结论：世界内容是否一致可信，读者正文是否清楚、可连续阅读。可读性问题定位到具体段落或相邻章节，说明问题是信息缺失、排序、重复、阅读强度还是表达载体；不要只用“AI 味重”概括。未经实际连续阅读或渲染检查，不宣称这两项已经通过。

| 检查项 | 可观察的验收依据 | 常见修复 |
|---|---|---|
| 入口与认识顺序 | 开篇能使新读者辨认地点、生活方式与特殊约束；必要知识在使用前得到说明；正文不被内部凡例和条文清单占据 | 从可见事务进入，移动背景与规则说明 |
| 覆盖与篇幅 | 目录、章节认识任务和预算相互对应；核心机制之外，人物生活、组织、地域与题材必需内容有足够位置；没有为凑字数复述 | 补真正缺失的尺度和后果，合并同功能材料 |
| 连续阅读强度 | 相邻小节有不同的信息工作；没有长期维持同一种正反论证和收束方式；说明之间可见空间、物件、事务与生活 | 调整章序、段落功能或载体，不按固定比例插入场景 |
| 规则的首述与再现 | 核心规则有清楚的主要解释位置；再出现时带来新条件、后果或必要例外；压缩后仍能找到适用范围与执行机制 | 保留一次完整解释，其余改为具体后果或必要回指 |
| 事务片段与人物 | 片段呈现可核对的行为、条件与结果；已发生、计划和假设有别；人物资源符合阶层，有非工作生活，跨章事实一致 | 补资源来源与日常动作，减少用途总结、对话剧情和心理展开 |
| 补充与文风 | 补充内容自然进入世界主题；正文不是连续字段、作者问答或每段一条观点；标题有辨识度又能指明内容 | 采用连贯叙述和世界主题标题，删掉重复评语 |
| 中文语感与观察变化 | 主体和动作可辨，技术限定保留；空间、机制、家庭、历史不是同一组名词化句与判词的复制 | 具体化行为，调整观察对象；不机械禁词或强行口语化 |
| 机制定位与地域反差 | 一项规则有主要解释位置；第四级只拆独立机制；外域开篇能看出共享规则和真实制度差别 | 合并碎标题，补同一事务的地区对照及跨域路径 |
| 目录与排版 | 遵循用户指定样式；所需层级、人物标签与实际正文对应；目录页码已核对；渲染后无溢出、孤立标题和异常空白 | 按 [docx-delivery.md](docx-delivery.md) 修复并复核 |

验收不使用统一人物数量、章节数量、场景比例、页数或固定汉字数。标题格式、篇幅和骨架允许由题材与用户要求调整。若读者版本身有事实冲突，仍按 S0/S1 等语义严重度处理；不要用阅读体验评分冲抵，也不要把轻微表达重复自动升级为世界不可行。

机械句式可以作为复查信号，不按命中次数自动判错。章末少于 200 字或不足 3 行是排版告警，需区分正常书末、目录与真正的孤行尾页；不能通过删除有效设定来消除告警。详见 DOCX 规范。

```markdown
- 连续阅读结论：
- 排版验证范围：

| 位置 | 可观察问题 | 对理解或阅读的影响 | 最小修复 |
|---|---|---|---|

## 本轮保留的结构与表达优势
```
