# 世界观到大纲的交接协议

生成 `设定/世界观/15_大纲接口.md` 或审查世界观/大纲兼容性时读取。

## 1. 单一所有权

| 内容 | 权威所有者 | 下游行为 |
|---|---|---|
| 世界硬规则、制度、势力、开篇正典状态 | 世界观 Skill | 大纲只引用，不复制改写 |
| 书级目标、人物弧、Arc、Sequence、章纲 | 大纲 Skill | 世界观 Skill 只做兼容审计 |
| 剧情计划造成的未来世界变化 | `追踪/世界状态变化.md` | 未发生前不得并入当前正典 |
| 正文已发生的事实 | 正文与连续性台账 | 世界观 evolve 模式核对后更新正典 |

世界观接口是版本化契约，不是大纲草稿。它提供可用压力和边界，但不决定主角是谁、必然选择什么或故事如何收尾。

## 3. 大纲侧引用文件

大纲 Skill 读取接口后创建 `大纲/世界观引用.md`：

```markdown

- 引用状态：active
- 接口模式：world-first
- 世界观来源：设定/世界观/世界观索引.md
- 世界观版本/状态：v0.1 / draft
- 接口文件：设定/世界观/15_大纲接口.md
- 正典基准时间：
- 锁定硬规则：RULE-001
- 选用结构冲突：CON-001
- 选用剧情种子：SEED-001
- 允许调整项：
- 禁止假设：
- 待确认：
```

该文件是指针与选择记录，不复制全部世界观。世界观内容庞大或有外部来源时，可补充源文件 SHA-256 或锁版 manifest 路径。

## 4. 大纲侧状态变化

`追踪/世界状态变化.md`：

```markdown

> 这里记录大纲计划，不代表当前正典。正文发生并核验后，才可交给世界观 evolve 模式合并。

| Change ID | 触发节点 | 前置世界状态 | 人物选择 | 直接后果 | 二阶后果 | 受影响 RULE/FAC/CON | 传播时延 | 可逆性 | 落地状态 |
|---|---|---|---|---|---|---|---|---|---|
```

## 5. 冲突处理

当大纲构想与世界观不兼容时，只能选择：

1. `适配剧情`：改变行动方案、资源、时序、角色知识或代价，保留 hard 规则。
2. `提出世界变更`：登记 `WCR-NNN`，说明所有下游影响，用户批准后更新接口版本。
3. `另开世界版本`：当改变核心约束、时代危机或主要制度时建立新大版本。

禁止在章纲中偷偷添加一次性豁免、未登记技术、万能关系或只对主角有效的制度漏洞。

## 6. 变更传播

世界观版本更新后，大纲必须检查：

- Story DNA 的类型承诺、核心阻力和独特机制。
- L1 的开篇/终局世界状态与信息轨。
- 所有引用受影响 RULE/CON/SEED 的 Arc、Sequence 和 Chapter。
- 时间、资源、身份、法律、知识状态与因果依赖。
- `追踪/世界状态变化.md` 中尚未发生的计划。

若大纲已锁定，使用 Change Request，不静默刷新引用版本。
