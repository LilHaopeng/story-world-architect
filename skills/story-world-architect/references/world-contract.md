# 世界观产物契约

创建、扩展或修订世界观时读取。本契约让 Markdown 设定既便于作者阅读，也能稳定交接给大纲和正文流程。

## 1. 所有权与兼容边界

- `设定/世界观/` 保存世界的当前正典、规则、结构冲突与下游接口，由世界观 Skill 维护。
- `大纲/` 保存计划，不得把尚未发生的剧情结果写回当前正典。
- `追踪/世界状态变化.md` 保存大纲拟议的世界变化，由大纲 Skill 维护；正文证实后才可并入 `14_当前世界状态.md`。
- `阅读版/正文.md`（或项目已有排版源）保存 reader 成稿；内部正典与正文必须使用一致事实。成稿新创的已采用设定须回写相应正典模块，不能长期形成两套实况源。
- `交付/*.docx` 是本次指定范围的排版快照，不取代 Markdown 正典；版本、状态、源文件/散列与覆盖映射保存在内部记录。reader 文档默认不展示这些制作信息；author 文档按需要展示。
- 现有项目若使用不同文件名，不强制搬迁。先建立索引和来源映射，再按需生成标准接口。
- 用户原稿、锁定版本和正文事实不可被初始化器覆盖。

`compact` 默认创建索引、工作状态、00、01、02、12、13、14、15 和变更记录。`standard` 再创建 03–11。`deep` 另建研究与模拟目录，但只在有实际研究问题时填充。

保持核心文件直接位于 `设定/世界观/*.md`，以兼容现有写作 Skill 的通配读取。

## 3. ID 与状态

| 对象 | 格式 | 示例 |
|---|---|---|
| 硬规则 | `RULE-NNN` | `RULE-003` |
| 制度 | `INST-NNN` | `INST-012` |
| 势力 | `FAC-NNN` | `FAC-007` |
| 历史债务 | `HIST-NNN` | `HIST-004` |
| 结构冲突 | `CON-NNN` | `CON-009` |
| 剧情种子 | `SEED-NNN` | `SEED-021` |
| 世界状态 | `WS-NNN` | `WS-005` |
| 世界变更请求 | `WCR-NNN` | `WCR-002` |

定义对象时以二级标题开头，例如 `## RULE-001 记忆可抵押`。锁定后不重编号；废弃对象标记 `retired`，不要复用 ID。

对象状态建议使用：`draft / reviewed / locked / active / dormant / resolved / retired`。正典级别使用：`hard / soft / belief / open / retired`。

各模块特别关注：

- `03_物理与空间.md`：地理、气候、交通、通信、距离和权力半径。
- `04_资源与生态.md`：稀缺、生产、再生、污染、垄断和分配。
- `05_力量与技术.md`：获得、使用、扩散、维护、反制、事故和制度适配。
- `06_经济与物流.md`：货币、信用、产权、劳动、供应链、税费、风险与尾部损失。
- `07_政治法律与制度.md`：授权、合法性、管辖、执法、申诉、失败、腐败和规避。
- `08_社会阶层与文化.md`：身份、家庭、教育、阶层流动、荣辱、礼仪、禁忌和惩罚。
- `09_历史债务.md`：仍在付息的战争、条约、灾难、特权、创伤与错误共识。
- `10_势力网络.md`：目标、资源、约束、策略、依赖、内部决策中心和可接受损失。
- `11_信息与治理能力.md`：记录、验证、传播、监控、伪造、保密、统计和决策盲区。

## 13. 版本语义

- `v0.x`：探索草案，允许 `open` 与待确认项。
- `v1.0`：首次完整锁定的开篇世界基线。
- `v1.x`：不改变核心世界命题和主要硬规则的兼容修订。
- `v2.0`：改变核心约束、时代危机、主要制度/势力结构或大纲接口的结构性重算。

版本目录不得覆盖；废弃版本保留并标记 `superseded`。

## 14. DOCX 最终交付

当本次任务包含世界设定集文档交付时生成一个 DOCX；仅核对、审查、接口或小幅增量维护不自动生成文档。reader 默认命名 `交付/{项目名}_世界设定集.docx`，已有版本采用不覆盖历史交付的命名；author 可沿用带版本的作者手册命名。收录范围、排版与逐页渲染验收见 [docx-delivery.md](docx-delivery.md)。

reader 按语义核对所有本次应介绍的有效设定：重要规则条件和例外必须明确，内部字段、ID、研究过程、剧情种子、审计和变更记录不要求逐字收入正文。author 完整汇编时才要求对象 ID 集合对账。两者的未收录理由都在内部覆盖记录说明，不能用删掉难懂规则制造易读假象。

DOCX 是派生快照：锁定版从对应版本快照生成；未锁定状态如实记在内部及最终回复，reader 默认不放 draft 横幅。正文不得包含未填占位符；仍未定的设置可自然说明范围或暂不下断言。交付后在 `世界观工作状态.md` 记录对象、路径、源版本、日期与 QA 结果。
