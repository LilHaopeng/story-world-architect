# 读者版世界设定集

用于面向爱好者、休闲读者的世界观目录、正文编排与阅读修订。目标是让读者理解一个世界怎样运转、人在其中怎样生活，并愿意继续读下去。它仍是理性的世界介绍，不按小说章节安排情节，也不把作者工作台的字段直接展示给读者。

规则、来源、正典级别、对象 ID、审计与变更记录仍在作者源文件中维护。读者版按认识顺序重组这些信息；不能因为改善文风而改掉规则条件、执行主体或重要例外。具体 DOCX 样式、目录与渲染交付读取 [docx-delivery.md](docx-delivery.md)。

## 1. 先确定读者会读到什么

新建或大幅重组时，先在对话中给出可核对的目录、各章认识任务、篇幅预算和核心正典边界，再填充正文。用户已经确认方案，或明确要求直接制作时，沿用已有授权，不为每章、每轮润色重复确认。日常增量修订可直接落实在既有结构中。

目录是阅读路线，不是模块清单。每章应回答一个相对独立的问题，例如人怎样出门工作、组织凭什么取得资源、地方为何作出不同选择。章节标题可以有生活质感，但应让读者知道将读到什么。

开篇先给具体地点、可见生活和最重要的特殊约束。通常不前置作者凡例、编制说明、术语总表、编号铁律、模块覆盖清单或修改经过。必要背景在首次需要它的地方解释；用户明确要作者手册、词典或附录时，再采用相应编排。

同时核对 [design-anchors.md](design-anchors.md) 中的现实参照、T0、基调与金额口径。内部锚点不前置给读者填表；通过地点、年代、生活尺度和清楚的机制说明自然建立。

### 目录既能连续读，也能定位机制

最多采用四级：章提供认识范围，节组织主题，小节交代一项机制，第四级定位确有独立内容的分项，例如多种资格、执行顺位、地域变体或估值情景。先确定每项规则的主要解释位置，再决定标题深度。第四级不是给每段加标签；只有一句定义时，可在同一小节内列举，不为目录数量扩写。

只收录实际标题，层级不跳跃；不强制所有章都到第四级。目录名称应能帮助读者知道“这条规则在哪里”，正文保留必要条件、过程和失败后果。后来再次涉及同一机制，写新增后果或短回指，不重新证明完整原则。需要金融、战争或亲密关系等衍生创作时，给足可选择的资源、约束与冲突，不替作者规定主角和结局。

## 2. 可调整的阅读骨架

下表是安排认识顺序时的备选骨架，不是固定章节数。按题材合并、拆分、前移或省略；故事依赖战争、生态或宗教时，应让这些内容进入主要路线，不必套成城市制度题材。

| 内容区 | 读者在这里获得什么 | 常用入口 |
|---|---|---|
| 生活入口与可见空间 | 先知道身处何地、普通一天怎样开始、哪些事与熟悉世界不同 | 一段通勤、一座村镇、一次补给、住处与街道 |
| 核心规则 | 理解本世界最重要的约束、适用条件、执行和失败后果 | 一个普通人办理或使用它的过程，配合必要说明 |
| 社会组织与工作 | 知道谁组织生产、雇人、分配资源，大小组织有何差异 | 企业、公共组织、行会、合作组织、宗族或其他本作组织 |
| 家庭、年龄与日常文化 | 理解教育、亲密关系、照护、休息、礼物和名誉怎样受世界影响 | 不同年龄家庭的安排，街道、节庆与非工作时间 |
| 地域与物质条件 | 获得距离、气候、生产、交通、住房和通信的尺度，理解地方差异 | 跨区出行、食物来源、季节变化、维护与故障 |
| 政权、机构与争议 | 知道权力由谁授予、怎样执行、哪里可以反对，暴力力量受何限制 | 地方决定、公共服务、申诉、执法或协商的实际路径 |
| 人物群像 | 通过不同位置的人，辨认资源、选择和代价的不平等 | 集中的人物介绍，也可与前文章节相互照应 |
| 历史形成 | 理解今天的规则、边界和不满从何而来 | 留有现实后果的旧事件、物件、制度变化与代际记忆 |
| 当前时代 | 明白此刻正在变化什么、谁想改变它、何事尚未有答案 | 正在进行的调整、不同群体的诉求、未完成的承诺 |

物质条件若是核心约束，应早于制度介绍；政治权力若决定日常安全，也不宜等到书末才出现。人物可分散穿行于各章，再集中介绍，不要求每章出场或彼此相识。不要把某一本书的章名、金融机制、人物名或章节数量移植为通用规范。

覆盖范围服从题材：制度密集世界应明确政权、执法和组织资源；冒险世界可能更需要补给、地形与危险边界。核心机制写深时，仍要留出足够篇幅给由它改变的世界，而非让全书变成该机制的使用说明。

### 地域先说明区别，再展开当地生活

介绍重要外域时，在开头或首个具体事务内让读者辨认它与主舞台的差别。可采用“同一件事在两地怎么办”的短对照：进入职业、取得资源、承担义务、寻求保护、迁出与迁入。写明共同的 hard 规则，再解释地方授权、主体、成本和执行尺度如何不同。不要靠极端制度猎奇或异国地名制造差异。

主舞台聚焦不等于外部世界不存在。按交往强度展开供应地、移民目的地、竞争者或远方传闻；只有传闻的区域不写成作者确证的制度百科。跨域差异必须与历史形成、经济条件和互认路径对得上。

## 3. 三种文字怎样分工

### 理性说明交代可复用的知识

用连贯段落说明常态、主体、条件、流程、成本和例外。首次建立核心规则时说清楚，避免读者只能从某个案例猜出规则。一般正文少用连续的“当前异常：”“核心问题：”“受益者：”字段；这类字段适合作者源文件或确实便于比较的表格。

不要每段都沿用“有合理一面—但是存在问题—另一方法仍有代价—必须留下边界”。一段可以直接交代怎样运转，一段说明已发生的变化，一段提供地方差异；需要权衡时再展开权衡。准确不等于每次都把正反论证重新做完。

### 中文语感和观察方式

优先让人、机构、物件承担动作，少让“边界、可能性、连续性、治理能力”一类抽象词串起整段。把翻译腔拆到能看见的行为，而不是换成更多形容词。以下只比较表达方式，不提供本作设定：

| 需要检查的写法 | 更具体的表达方向 |
|---|---|
| 迁移产生了照护网络可达性的下降 | 搬家后，原来轮流看孩子的两户邻居都不在步行范围内了 |
| 收入预期收缩导致履约弹性承压 | 厂里取消夜班，工资少了一截，月底的应付款没有变 |
| 系统能记录资源，不能替人维护生活 | 若前文已说清，删掉判词；直接写负责检修的人少了两名，哪些维修被推迟 |

不是禁止抽象词、被动句或对比句。检查的是连续出现的空主语、层层名词化、拗口拟人和“能做 X，不能替人做 Y”式裁判结语。朗读相邻段落；若换了章节仍像同一份政策摘要，换观察对象和句子工作，不做同义词洗稿。

观察方式由内容选择：空间章沿街道、运输或建筑展开；机制章跟踪一次输入、处理和结果；家庭章写时间安排与人情往来；历史章选转折和遗留后果；人物章写当前生活与资源来路。不是每章贴一个新文体标签，也不要用暴烈比喻代替准确因果。描述、说明、短事务与对照可以自然交替，保留整体叙述声音。

### 短事务片段提供现实落点

优先写人在处理一件具体事务：要做什么、手头有什么、遇到哪项条件、接下来怎样办理。片段可以让规则、时间和资源碰到一起，随后由说明交代一般情况。它不必有戏剧冲突，也不必替人物完成选择。

控制对话、心理发展、悬念和情绪高潮；不要把设定集改写成连续小说。已经发生的事、当下常态、人物计划和仅有可能的后果应措辞清楚，不能靠具体细节把假设写成已发生的正典。

写法示例，仅演示信息载体，不提供任何作品的世界事实：

> 说明写法：补给延误会影响轨道站的维护优先级。
>
> 事务片段写法：补给船晚到两天，轨道站先更换居住舱的滤芯，观景廊的检修排到下一班。维护员把剩余零件重新贴签，来访者仍能看到窗外，却少了一条可通行的走廊。

不用为了达到一个场景比例，把每项制度都安排成某人去一次窗口。对照、空间描述、物件、沿一次生产或服务过程展开，也能改变阅读节奏。允许短段只提供天气、尺度、手艺或生活质感，不必在结尾提炼观点。

运行机制的检查留在内部推演，读者正文呈现被它改变的事务、关系、习惯和选择，不为每个生活细节重新补一段完整因果论证。文化共识通过实际奖惩与不同人的行为显现，不用一句“这里的人都认为”包办整个社会；对本作确有依据的共同信念仍可概述，再在必要处说明差异。

### 人物介绍呈现位置与生活

人物群像按本作真实社会差异设计，考虑不同阶层、派系、地域、年龄、性别和职业，不把人口维度逐格填满当成任务。每人的资源来源、能决定什么、受何限制应有区别；高层人物应有与地位相称的资产、关系、继承或组织支持，不能只换一个头衔，仍过着普通人的资源生活。

用叙述交代他们在做什么、为什么处在这里、有哪些工作以外的关系、兴趣与习惯。避免以“此人用于说明某制度”收束，也不把人物写成一种立场的代言器。人物可以矛盾、变化和意见不一致；不必给每个人配套完整故事弧。

在人物目录中，默认采用“姓名（性别，年龄，职业或身份）”的标题，便于快速定位；用户另有规范时遵循其要求。正文可展开经历，无需把标题信息机械重说。人物在多章出现时核对住处、职业、关系和事件顺序；只有现有材料支持时才建立连续的小段生活过程。

机制章可使用匿名行业切片，不必每次召回同一组人物。核心人物在其他章出现时应有新的时间、处境或认识作用；集中小传不再逐条复述前文事例。少数连续生活线可以保留，不设“人物只能出现一次”的禁令。内部可用 `CHAR-NNN` 核对年龄、资源来源和当前活动，编号不进入 reader 正文。

## 4. 篇幅先做预算，再分配信息

篇幅随世界规模、读者耐心和既有内容确定。与多地域、社会制度较丰富的长篇设定集相近时，正文约 4–6 万汉字可作为讨论起点，不能作为最低字数、质量标准或所有题材的默认目标。较小世界可明显更短；资料更丰富也不意味着应全部前置给读者。

核对方案时给出正文总量和各章预算，说明预算是否包含人物、表格与补充内容；目录、页眉页脚和作者台账不混入正文计数。页数受字体、字号、留白和纸张影响，不能由字数直接承诺。

篇幅优先留给独特生活、必要逻辑、组织与地域差异，再分给增强细节。需要压缩时，先处理重复论证、重复规则和同功能案例，不能只删掉人物、生活或规则执行条件。需要扩充时，补缺失的尺度、因果与具体经验，不用近义反复撑长文本。

## 5. 修订时检查阅读强度

按实际阅读顺序连续检查，不只逐章单独审。寻找以下现象：

- 多个相邻小节都以同样长度、同样正反结构或同样结语展开。
- 每段都有制度判断，读者没有空间观察地方、物件或日常动作。
- 几章连续介绍机构、权限、流程，尚未看到它们作用于生活。
- 已建立的核心原则在新章节中再次完整论证，却没有新增条件或后果。
- 人物反复只为不同制度提供例证，处境和生活没有可辨认的连续性。
- 改成场景后更好读，但规则的适用范围、执行者或重要限制变得不可查。

据实际问题调整：移动说明、合并重复、换成短事务片段、使用必要对照、补一段物质或生活观察。不要固定“每几页一个场景”，也不要靠删设定制造轻快。规则一致性与可读性分别审查；读起来顺不能抵消硬规则矛盾，规则完整也不能证明适合连续阅读。审查项见 [audit-rubric.md](audit-rubric.md) 的读者版部分。

## 6. 补充内容与最终正文

补充说明放到读者需要它的位置，采用与世界同步的主题标题，例如“跨城之后的证明”“冬季储粮”“祭司如何确认继任”。通常不另设“读者常问”“作者答疑”附页，让读者跳出世界再向作者求解释。世界内标题也不意味着必须伪装成公告、档案或角色自述，清楚的第三人称叙述即可。

读者版不默认展示稿次、变更记录、工作流程、审计分数、未完成清单或对象 ID。作者工作台保留追踪；如果有真实未定内容，正文不把它包装成确定事实。用户要求披露编制状态或来源时，按其指定范围编排。

最终交付前，分别核对源文件覆盖、正典一致性、连续阅读及 DOCX 视觉效果。记录未纳入正文的内部材料及原因，避免无意漏掉关键世界信息；不为追求覆盖，把所有台账原样塞回正文。
